# Движок «Графа идеи» (idea-graph-engine)

Всё про проект и агентов, без интерфейса. Цепочка линейна: сфера → конкуренты → анализ → роли → сценарии → как есть → решение.

| Что | Как работает |
|---|---|
| `Project` | Граф (`idea-graph-core`) и банк знаний `knowledge` (конкуренты, факты, требования). Действия человека: принять, отклонить, удалить, написать своё, шаги диаграммы текстом |
| Исследователи | Три агента на разных моделях с веб-поиском ищут и анализируют сайты конкурентов; результаты объединяются без дублей |
| Помощник | Предлагает роли, сценарии, проблемы, варианты автоматизации и строит диаграммы. Добавляет только карточки «предложена»; в спорной ситуации задаёт один вопрос с вариантами и продолжает с ответом |
| Автопилот | Сильная модель: до 15 вопросов о границах системы (ответы — требования в банке), затем проходит цепочку сама, принимая и отклоняя предложения (`decide`) |
| Инструменты агентов | Помощник: `graph_apply` (только `add_card` нужных видов, диаграммы проверяются), `ask`, `finish`. Исследователь: `report`. Файлов и терминала нет |
| Запоминание | Отклонённое и удалённое не предлагается снова (`.idea-graph/flow.json`) |
| `diagrams.py` | Данные UML-диаграмм: последовательности (`parse_text`, `to_text`, `to_mermaid`) и вариантов использования |

Агенты запускаются через `agents.py`: Claude Code и OpenCode (модели подписки Go, усилие — вариант модели). Один ход — один запуск;
инструменты агент вызывает через MCP-мост `mcp_proxy.py`, который пересылает вызовы работающей оболочке.

Настройки (`~/.idea-graph/settings.json`, папка меняется переменной `IDEA_GRAPH_HOME`): помощник, автопилот, три исследователя, корневая папка проектов.

## Выгрузка документации и проверка согласованности

Кнопка «Выгрузить .md» запускает работу `export`: сначала проверка графа, потом файл `Документация.md` в папке проекта.
Документ — только отражение графа, поэтому разногласия исправляются в графе, до выгрузки.

- Код находит точные разногласия: принятая проблема без выбранного решения, пустые описания и важность, роль вне сценариев,
  сценарий без ролей, нет диаграмм или они построены по устаревшим проблемам и решениям.
- Сильная модель (настройка «Автопилот») находит смысловые: карточка противоречит границам системы, решения противоречат друг другу,
  роли и сценарии не сходятся.
- По каждому разногласию человеку задаётся один закрытый вопрос; каждый вариант — правка графа (убрать карточку, выбрать другое
  решение, предложить новые варианты, исправить текст, перестроить диаграммы). Варианта «оставить как есть» нет.
- Пока код видит разногласия, закончить проверку нельзя. Файл записывается, когда разногласий не осталось.
- «Выгрузить .md автоматически» (`export_auto`): без вопросов. Агент правит граф сам: вне границ и спорное убирает, из двух
  противоречащих — ту, что хуже соответствует границам (при равенстве — созданную позже); проблему без решения — выбирает
  лучший вариант в границах, нет подходящего — убирает проблему; пустую карточку дописывает по названию или убирает.

## Автопилот «по сценариям»

Галочка при запуске автопилота (`start autopilot each=true`). Конкуренты, анализ и все роли — как обычно; дальше сценарии по одному:
агент предлагает ОДИН следующий сценарий (или говорит «основное покрыто» и ничего не создаёт), автопилот принимает или отклоняет его,
сценарий проходит проблемы → «как есть» → решения → «решение», и только потом начинается следующий. Каждый следующий шаг видит,
что уже построено по прежним сценариям (проблемы и выбранные решения). Уже имеющиеся сценарии сначала доводятся по одному.
Проблема, для которой в границах нет решения, убирается из графа, а «как есть» перестраивается. Предохранитель: не больше 8
сценариев за прогон; два отклонённых подряд — остановка.

## Жёсткие правила при создании

Агент не может создать нарушающее правила: пакет отклоняет карточки с точным текстом, агент исправляет и повторяет.
Описание проблемы и варианта — до 250 символов. «Как есть»: каждая принятая проблема отмечена на шаге (`pain.what` — точное
название), других нет, шагов «сам себе» нет, не больше 12 шагов. «Решение»: каждый изменённый шаг называет решение (`by`),
каждое выбранное решение есть хотя бы в одном шаге. Вопросы агентов: вопрос до 120 символов, варианты до 60, без пояснений.
- В документе: границы, конкуренты (без находок анализа), роли, сценарии с проблемами, решениями и таблицами шагов, предложенное
  и не принятое — отдельным разделом.
