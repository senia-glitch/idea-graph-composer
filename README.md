# Движок «Графа идеи» (idea-graph-engine)

Всё про агентов и этапы, без интерфейса: запуск Claude Code и OpenCode, ход пакета-этапа, ворота шагов,
совет из трёх агентов, независимое ревью, исследователи, предложения правок, банки проекта.
Интерфейс — в `idea-graph-shell`; движок можно использовать и отдельно (например, в тестах и скриптах).

## Что умеет

| Механика | Как работает |
|---|---|
| **Ход пакета** | Агент получает вводные, меняет граф инструментами (`graph_apply`), задаёт один вопрос с вариантами (`ask`), заканчивает `finish`. Ответ человека приходит в следующих вводных |
| **Помощник шага** | `Project.start(пакет, step=…, action=…)`: «предложить», «проверить», «уточнить», «сгенерировать» — тот же ход с вводными шага из декларации этапа |
| **Ревью** | Действие «проверить» идёт на отдельном слоте модели («Ревьюер») и может только добавлять карточки «замечание» |
| **Ворота** | `approve_step` / `reopen_step`: шаг утверждает только человек; нельзя утвердить пустой шаг или оставить непринятое без явного согласия |
| **Устаревание** | Человек правит утверждённую карточку → зависимые шаги получают отметку, а помощник по умолчанию сам предлагает «правки» (карточки, которые человек применяет или отклоняет) |
| **Исследователи** | Три агента на разных моделях с веб-поиском и ресурсами пользователя; режимы «всем одно задание» и «по заданию на каждого» |
| **Автоматический режим** | Очередь «цель × шаг»; вопросов человеку нет, на развилках решает **совет** из трёх советников |
| **Совет** | Каждый советник независимо отвечает с обоснованием; при расхождении один круг обсуждения; итог — большинство, обоснование 2–3 фразы + «особое мнение» попадают в карточку |
| **Банки** | Инструменты агента `bank_read` / `bank_write` (доступ по манифесту пакета); записанное агентом ждёт принятия человеком |

## Как этап подключается

Пакет объявляет точку входа `idea_graph.packages` и возвращает манифест со словарём `stage`: шаги (вопрос, что создаёт,
от чего зависит, ворота, промпты действий), виды карточек (цвет, поля, чипы связей, отрисовка), банки, автоматический режим,
исследование. Полный список полей — в `packages.py`. Новый этап не требует правок движка и оболочки.

Настройки (`~/.idea-graph/settings.json`, папка меняется переменной `IDEA_GRAPH_HOME`): слоты моделей помощника, трёх исследователей,
трёх советников и ревьюера; флаги автоматического режима.

## Установка и тесты
