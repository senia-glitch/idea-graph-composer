# Компоновщик

Добавляет в оболочку экран «Конвейер»: карта пакетов и прогон по ней. Узел — пакет, стрелка —
«после этого запускать то» при заданном итоге пакета. Прогон идёт по шагам или автоматически;
у каждой стрелки есть предел числа проходов.

Карты хранятся в `~/.ideagraph/maps`, состояние прогона — в папке идеи. Модели в пакете нет.

## Установка

```
pip install -e .
```

Нужны `ideagraph-core` и `ideagraph-shell`.

## Тесты

```
pip install pytest
python -m pytest
```
